# 玻璃与任务板动效修正 · 0.3.0

日期：2026-10-27。状态：已构建、校验并覆盖安装到连接手机，待用户体验验收。

## 用户要求

玻璃框直接参照用户图二：更充分的局部背景模糊、柔和底部阴影、白色细边框、更圆的面板及按钮。任务板重新核对《产品需求与设计决策》第 3.1 节，恢复同时增宽增高、邻卡变窄变高、文字淡出、下方卡片平滑移位与弹性回弹。

## 实施

- 材质共用于新建、详情、材料、搜索和周计划。以实际背景快照降采样并在后台作三轮可分离模糊，再按面板实际坐标裁切显示；采样先铺不透明画布，避免透明背景被当作黑色。面板圆角 22dp，白色边框透明度 .88，近白渐变 .69 → .51，背景饱和度 1.35；模糊核参考半径 16dp，底部阴影高度 24dp，创建按钮圆角 11dp。框外仅叠加 .025 黑色以轻微降明度。参数是 Android 还原值，不宣称与 CSS 单位逐像素等同。
- 任务板改为自定义测量布局：同一个进度控制物理宽高、邻卡面积近似保持、文字透明度和行高。使用阻尼比 .48、刚度 170 的弹簧，允许超调并可被下一次点击中断。正文保持测量，动画状态在测量或绘制阶段读取，避免每帧重组和重新排版整段文字。普通页面不再持续录制背景 GraphicsLayer。
- 隐藏正文的点击和语义同步禁用，避免尚未展开时被不可见子控件截获。原有滚动、点击收回、长按槽位移动保留。

## 验证

- 规则测试 12 项通过（domain 9、data 3），包括新增邻卡面积、连续高度与超调检查；构建及 Android Lint 通过，Lint 0 错误。调试签名校验通过。
- API 36.1 模拟器，读取实际原生卡片尺寸：27 个不同中间尺寸；课程卡由 471×389px 展开到 692×840px，宽度曾达到 725px 后回到 692px，确认实际发生弹性超调。连续点击收回检查通过。此记录不是手机帧率或高刷新率性能结论。
- 新建、材料、搜索、周计划截图已查看；背景模糊准备未触发不透明回退，样机无捕获到的运行时异常。录屏与报告：`android/review/material-motion-0.3.0/`，其中 `board-motion.mp4` 为单独录制的实际原生画面；尺寸测量时没有同时运行软件录像编码器。
- `artifacts/Agenda-motion-0.3.0-debug.apk` 已覆盖安装成功，手机系统报告 `versionCode=3`、`versionName=0.3.0-motion`。本轮没有自动操作手机界面；由用户打开体验。

## 边界

玻璃使用打开面板时的静态背景快照；当前遮罩阻止操作底层内容。真实设备的手感、性能、系统减少动画及 Android 12 全面兼容仍需后续验收。仍为内存演示样机，未扩展生产数据功能。

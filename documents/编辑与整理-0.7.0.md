# 编辑与整理：0.7.0 交付记录

日期：2026-10-29。对应《正式版补全执行计划》批次 A；这是开发版本，不代表正式版全部范围完成。

## 已完成

- 任务详情的「编辑任务」复用原表单，带入名称、类别、归属、截止日期及意愿；可改为另一对象或独立任务，可清除日期和类别。
- 对象「材料／说明」列表和展开后的任务板卡片提供「编辑对象」；对象搜索结果也可进入改名表单。
- 说明详情提供「编辑说明」，修改标题与多行正文；外部仍只显示标题。
- 点击日程内容进入编辑，可改日期、时段、钟点、独立显示名称或内容来源，勾选区继续负责完成操作。
- 周计划每条提供「编辑」，保持当前查看周、记录 ID 与独立完成状态；不进入普通任务列表。
- 材料标题与说明编辑继续沿用 0.6.2；所有表单沿用已认可的玻璃材质。

## 数据规则

本批不变更 schema，继续使用 v3。全部编辑在原 ID 上事务更新，保留创建时间、已有完成态和关联，不以删除重建代替编辑。任务移动只改变自身归属，不移动原对象的材料与说明。

任务改名后，默认名称的日程跟随，独立显示名称保持。日程判重排除自身，不能与另一引用产生同任务、日期、时段、钟点的重复；冲突时整次更新回退。临时项保留自身完成态；引用转临时项继承当时有效完成态，临时项转引用读取目标任务状态，不修改目标或原任务。

必填为空显示错误；保存失败保留输入；未保存关闭提示继续编辑或放弃。周计划表单的取消表示放弃本次输入。

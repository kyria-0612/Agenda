# 交互与材质修正 · 0.4.0

日期：2026-10-28。状态：已完成最终原生回归，交付 0.4.0，待用户集中体验验收。

## 修改与原因

- 关系图：移除受限 Box 中 oversized requiredSize 引入的额外居中偏移，以独立世界尺寸测量并明确放置原点，再应用概览平移与缩放。
- 玻璃：沿用保存的原图，不要求用户重发。0.3.0 的色面和模糊叠加遮住了轮廓；本轮近白遮盖透明度改为 .32 → .16，参考模糊核半径 9dp、饱和度 1.15，保留边框和柔和阴影。实际效果以 `05-translucent-glass.png` 为证据，不能只看参数。
- 日期：用有独立星期表头、月份导航和选中格子的月历替代 ISO 日期底线输入；类别、归属/日期/意愿和快捷日期改为有实底选中态的圆角选项，区分操作层级。
- 材料/说明：点击关系图的对应分支，分别打开内容列表和添加入口。说明可多行填写并保存到该对象；材料通过系统选择器读取，再复制到应用私有目录，通过 FileProvider 打开副本。取消选择、读取失败和没有打开程序有反馈。它们不混入新任务表单。
- 任务板/行动：共用 `ExpandablePair`，所有收起卡片覆盖完整点击区域；固定正文阅读宽度并连续改变外框，缩小侧卡挤压比例。共用弹簧参数 .86 / 360，连续点击保留速度，避免 0.3.0 强超调与过窄挤压。收起标题在自身可用宽度内换行。
- 悬挂日期：用同一套弹簧驱动宽高，紧凑与展开内容保持测量并交接透明度；不再在宽度动画途中突然替换内容。展开卡片圆角 16dp，保留聚焦居中和内部滚动。

## 方案参考

查阅 [Android shared bounds / container transform](https://developer.android.com/develop/ui/compose/animation/shared-elements)、[Android 动画指导](https://developer.android.google.cn/develop/ui/compose/animation/quick-guide?hl=en)和 [Apple spring 连续速度](https://developer.apple.com/de/documentation/swiftui/animation/spring)。本轮使用现有 Compose 工具实现原位容器形变，统一布局与运动参数；没有引入另一套动画框架。也不把引用平台原则写成已复制某个 Apple 成品动画。

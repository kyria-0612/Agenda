# 删除与短暂撤销：0.8.0 交付记录

日期：2026-10-29。对应《正式版补全执行计划》批次 B；仍为开发版本。

## 本轮功能

- 对象、任务、材料、说明、日程和周计划提供删除入口，统一使用已认可的页面内玻璃确认卡片。
- 确认前列出对象、任务、材料、说明、关联日程或周计划的受影响数量；取消不改变内容。确认期间数据发生变化时刷新预览，必须再次确认。
- 删除对象，删除其当前所属任务、材料和说明，以及这些任务的引用日程。删除任务，删除其引用日程，保留对象的共享材料和说明。
- 单独删除材料、说明、日程或周计划，仅处理该条目；删除引用日程不删除任务，也不改变任务完成状态。
- 删除后底部显示撤销操作。默认 8 秒，遵守系统辅助功能建议时长，确认框显示实际秒数；每次删除有独立操作记录和撤销入口。
- 撤销恢复整组原 ID、字段、完成状态、显示名称、归属和材料副本。依赖不存在或引用冲突时整次撤销回退，不覆盖新记录，仍在时限内可重试。
- 日程有未保存修改时，删除入口禁用，避免静默丢失草稿；材料信息编辑中不显示删除按钮。

## 数据与中断处理

Schema 3 → 4 显式新增 `agenda_delete_undo`，旧表不重建。删除和完整恢复集写入在同一事务内完成，查询立即不再显示已删除内容；不会暴露回收站。

撤销截止时间随操作持久保存。应用内部导航不取消撤销；进程重启后，未到期的操作继续提供剩余窗口，到期操作继续清理。系统时间回拨到操作创建时间之前时保守结束撤销，不无限延长窗口。

附件清理在后台线程执行：撤销期内的副本仍受操作记录保护，超过时限才作为无引用文件清理。应用未运行时可延至下次启动清理。只处理应用内部受管文件，不删除用户手机上的原文件。复制与清理共用互斥保护；活动材料与暂存恢复集在一致读事务中共同决定文件保留范围。

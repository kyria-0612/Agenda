# Agenda 整体视觉设计规范 · 第一版

状态：已确认视觉方向。确认日期：2026-10-20。

最终方案为「浅色炭灰青 + 低饱和灰蓝」，对应炭灰青版本对比中的 V2，灰蓝为 **#3B4F62**。原浅色炭灰青 V1 作为历史基线保留。本文件是后续设计与开发的视觉依据。

本轮确认整体视觉风格、配色、字体分工、图标语言和玻璃材质方向。试色页只用于判断视觉，不是新的页面架构或交互定稿。

| 内容 | 当前结论 |
| --- | --- |
| 浅色为主、炭灰正文、青色选中、灰蓝强调 | 已确认 |
| 英文字母、数字、中文标题、中文正文的字体分工 | 已确认 |
| 统一线性图标与轻盈玻璃浮层方向 | 已确认 |
| 事项页添加日程的布局与入口位置 | 以此前敲定的交互原型为准，不采用试色页偏差 |
| 第三个页面「日历／日程」的结构 | 保留此前敲定的悬挂卡片与横向卡片流，不被试色页简化结构替代 |
| 不同弹框当前呈现的玻璃化程度 | 尚未逐框定稿；保留材质方向，后续单独校准 |

有冲突时：用户最新明确决定优先；视觉按本规范，布局与行为按此前确认的需求和交互原型。无法从既有记录判定的差异列入待核对项，不以试色页补全事实。

## 2. 整体风格

浅、静、清楚，有轻微纸页阅读感，同时保留现代工具的精确性。大面积使用浅灰与近白，炭灰建立阅读层级，灰蓝强调操作，青色标记当前时间与选中态。

中文衬线标题提供温和的阅读气质，中文无衬线正文保证任务密集时的清晰度。英文与数字具有独立字形，统一混排节奏。玻璃用来表达浮层与底层内容的关系，普通内容卡片采用稳定实底。

深色不再作为大面积画布；灰蓝也不铺满页面。避免高饱和蓝、霓虹发光、彩色大渐变，以及仅为装饰增加的玻璃卡片。

## 3. 配色与角色

| 语义角色 | 色值 | 用途 |
| --- | --- | --- |
| 主画布 | **#EEEEEE** | 页面大面积背景 |
| 内容面 | **#FAFAFA** | 普通内容卡片、菜单兜底面 |
| 正文 | **#222831** | 任务名称、正文、主要数字 |
| 中性标题／图标基色 | **#393E46** | 非强调图标、中性文字层级；不是所有标题的默认色 |
| 辅助文字 | **#59616B** | 时间、说明、次级信息 |
| 灰蓝强调 | **#3B4F62** | 页面及分组标题、品牌字样、主要按钮、当前导航、文字操作 |
| 青色选中 | **#00ADB5** | 当前日期、明确的选中面 |
| 青色面上文字 | **#222831** | 青色日期与数字；避免直接放白色小字 |
| 主要按钮文字 | **#FAFAFA** | 灰蓝实色按钮上的文字与图标 |
| 深青控件边界 | **#00767C** | 完成框边界、需清晰识别的青色控件 |
| 浅青辅助面 | **#DCEFF0** | 轻量选中、悬停辅助背景 |
| 分隔线 | **#CDD2D6** | 内容边界与分隔 |
| 提醒／错误 | **#A13E36** | 需要处理的错误与提醒，配合文案或图标 |
| 完成反馈 | **#376C60** | 已完成提示；不能只靠颜色区分状态 |

灰蓝负责操作与层级，青色负责当前与选中。两者应具有稳定分工，避免同一层级按钮随机换色。灰蓝从早期 #234D70 调低饱和后确定为 #3B4F62；后续不得误用旧蓝。

正文、辅助文字与提醒色为静态角色值；透明面需结合实际底图检查。灰蓝在浅灰背景上的对比约 7.30:1，在近白内容面上约 8.11:1；灰蓝主要按钮的近白文字同样约 8.11:1。普通小字至少 4.5:1，控件关键边界至少 3:1。以上不等于所有页面已完成无障碍验收。

## 4. 字体与混排

| 字符／用途 | 字体 | 来源与分工 |
| --- | --- | --- |
| 英文字母 | **Space Grotesk** | 沿用「夜航」方案，包含 Agenda 品牌字与界面英文 |
| 数字 | **Manrope** | 沿用「纸页手帐」，覆盖日期、时间、数量、状态栏数字 |
| 中文标题 | **Noto Serif SC** | 本地别名 Agenda Serif；页面标题、分组标题与需要阅读感的提示 |
| 中文正文 | **Noto Sans SC** | 本地别名 Agenda Sans；任务、表单、按钮、说明文字 |

通过字体别名 **Agenda Mixed** 的 unicode-range 将英文字母与数字分别路由到 Space Grotesk、Manrope。标题栈为 Agenda Mixed → Agenda Serif，正文栈为 Agenda Mixed → Agenda Sans。数字与 ASCII 标点跟随 Manrope；中文字符及中文标点使用对应中文字体。

不能用 Space Grotesk 覆盖全部数字，也不能用 Manrope 覆盖英文字母；不能因为标题用了宋体就把按钮和任务正文都换成宋体。字体优先本地加载，回退只用于缺字或加载异常。日期、时间和计数宜使用等宽数字特性 `tabular-nums`。

### 字号与节奏参考

以下提取自视觉原型，属于后续排版基线，不代表页面尺寸与布局已定稿；试色页在不同宽度存在缩放规则，不能将其全部固化。

| 层级 | 参考值 | 规则 |
| --- | --- | --- |
| 页面标题 | 24px 左右，常规字重 | 中文衬线；字距 0.01em，行高约 1.4 |
| 分组／浮层标题 | 17–20px，约 500 字重 | 中文衬线；浮层标题参考 20px |
| 任务与正文 | 14–15px，常规字重 | 中文无衬线，行高约 1.4–1.6 |
| 时间与辅助说明 | 12–13px | 控制信息密度，保证对比度 |
| 日期条数字 | 25px 左右，400 字重 | Manrope；数字行高约 1.3 |
| 展开日期大数字 | 38px 左右，400 字重 | Manrope；行高约 1.1 |
| Agenda 品牌字 | 16px 左右 | 英文 Space Grotesk |

小字号不以过浅灰色换取轻盈感。标题、正文与数字的字号差要服务信息层级；长任务名换行，不能为保持卡片整齐而隐藏关键内容。

## 5. 图标与导航

使用当前 **Agenda Line** 线性图标体系：24px 设计网格，常用显示约 21px，线宽 1.5px，平端线条，转角保持统一。特殊紧凑区域可按比例缩小，不能混入不同粗细、圆端或填充风格图标。

默认图标采用炭灰／中性色；当前导航使用灰蓝 #3B4F62，并保留方点选中标记。底部导航继续沿用此前确认的纯图标设计与交互，各入口提供明确的辅助技术名称。

新增、搜索、日历、关系、行动、返回和关闭等使用同套图标。图标可见尺寸与可点击区域分开处理；点击区域参考至少 44×44 CSS px，最终 Android 以原生平台触控规范核对。

## 6. 材质、圆角与层次

普通工作卡片采用近白稳定内容面，以浅灰背景、细边界和留白分层。浮层使用浅色半透明玻璃，背景内容被模糊但仍可感知；不把所有内容卡片都玻璃化。

### 玻璃材质的技术参考

以下是当前视觉原型的参考起点，**不是对所有弹框玻璃化程度的最终验收**：

```css
background: linear-gradient(145deg,
  rgba(250, 250, 250, 0.64),
  rgba(250, 250, 250, 0.32));
backdrop-filter: blur(12px) saturate(130%);
-webkit-backdrop-filter: blur(12px) saturate(130%);
border: 1px solid rgba(255, 255, 255, 0.82);
border-radius: 18px;
box-shadow: 0 16px 36px rgba(34, 40, 49, 0.16),
            inset 0 1px 0 rgba(255, 255, 255, 0.8);
```

新增日程、搜索、周计划、材料／说明详情等浮层采用同一材质语言。当前各框的实际通透程度存在差异，后续在恢复正确布局后，结合背景内容、尺寸与阅读密度逐框统一；不要把不同页面偶然呈现的透明度差异当作设计规范。

输入区保持透明或轻量边界，避免内部再叠厚重实色块；主要按钮保持实色灰蓝。浏览器不支持背景模糊时，退回近白 #FAFAFA 实色，保证内容可读。

普通卡片圆角参考 8px；玻璃浮层和实心操作按钮按 2026-10-27 用户图二更新为更圆的轮廓，Android 样机分别采用 22dp 和 11dp，覆盖此前浮层 18px、紧凑按钮 5–6px 的初始参考。原型手机外框的圆角、阴影与尺寸只是展示容器，不属于应用组件。具体卡片形状应服从此前已确认的悬挂卡片、横向卡片流和原位展开结构。

## 7. 组件与状态应用

| 组件／状态 | 视觉规则 |
| --- | --- |
| 主要按钮 | 灰蓝底 #3B4F62，近白字 #FAFAFA |
| 文字操作 | 灰蓝文字；清楚区分可点操作与辅助说明 |
| 日期选中 | 青色 #00ADB5，炭灰数字／文字 #222831 |
| 完成框 | 未完成使用深青清晰边界；完成态配勾选图标，原型可用灰蓝底与近白勾 |
| 错误／提醒 | 红色 #A13E36，加可理解的说明；不只变色 |
| 完成反馈 | 绿色 #376C60，搭配完成标记或文字 |
| 禁用 | 低强调文字与浅辅助面，保留轮廓；不得造成仍可点击的误解 |
| 焦点 | 清楚可见的灰蓝轮廓；表单使用灰蓝底线反馈 |
| 空状态 | 保留留白与可执行入口，不用大面积装饰挤占任务空间 |

控件反馈约 160ms，展开／收起约 220ms，尊重系统减少动态效果设置。具体缓动、各组件动效与禁用透明度尚未逐项定稿，后续沿用既有交互并单独校准。

任务板的形变不适用固定 220ms 的通用展开时长：按产品交互要求，用同一个可中断弹簧连续驱动展开卡片宽高、邻卡挤压和下方行位移，保留可见超调与回弹；压缩邻卡近似保持面积，文字随挤压淡出。不能用内容瞬间替换或只有最终截图代替动效验收。

## 8. 后续落地与待核对项

1. 把此视觉系统应用到原先确认的交互结构；不以试色页面重写页面行为。
2. 还原事项页添加日程的原有布局与入口关系。
3. 日历／日程页保留悬挂卡片、横向卡片流以及既定展开关系。
4. 分别复核新增日程、搜索、周计划、详情框的玻璃材质，统一视觉强度并检查实际背景上的文字可读性。
5. 检查字体缺字、长内容、数字对齐、触控区域、焦点和减少动态效果。
6. 核对全页配色角色，清除旧深蓝 #234D70 和试色展示页自带的绿色选中样式；展示工具的控件颜色不是产品颜色。

本次只记录确认与后续要求，不在本轮修改上述布局差异，也不宣称正式交互原型已经完成最终视觉落地。

## 9. 项目内参考

### 2026-10-27 真机反馈补充

- 用户明确要求详情、材料、新任务、搜索和周计划均使用有浅色边框的页面内玻璃卡片；取消整页强模糊与明显变暗。
- 浮层背后局部模糊，框外内容仅轻微降低明度且保持可辨。此要求优先于早期整页模糊的原生样机实现。
- 新任务回到页面底部，恢复名称、执行类别及可展开的归属／截止日期／意愿；搜索从顶部展开，周计划从右上入口位置展开。
- 图三继续作为最终灰蓝、青色及字体角色的依据；图一图二的旧绿色不替换确认的灰蓝主操作色。
- Agenda 顶部按整个视口真正居中并略加粗；任务板增加适度弹性；悬挂日期展开自动聚焦。参数和效果需继续真机体验。
- 用户参考图已保存于 `android/review/feedback-2026-10-27/references/`，本轮实施和验证见《真机反馈修复-2026-10-27》。
- 追加反馈要求直接以图二校准玻璃强度、底部柔和阴影与按钮圆角。0.3.0 改为真实背景栅格模糊后再叠加半透明渐变；面板外维持轻微降明度。参数、逐帧证据及边界见《玻璃与任务板动效修正-0.3.0》。
- 2026-10-28 反馈覆盖 0.3.0 强度：玻璃要能辨认背景的模糊轮廓，降低近白遮盖并缩小模糊核；任务板与行动必须使用同款、克制且可中断的容器展开，不追求夸张挤压或强超调。悬挂卡片保持内容交接并稍增圆角。日期区域采用有层级的选项和月历，不再把表头、数据和所有选项都画成底线文字。见《交互与材质修正-0.4.0》。
- 0.5.0 追加要求：玻璃第一帧即为最终材质，取消旧不透明兜底面板的可见切换；悬挂日期收起期间避免分批加载详情和延迟居中校正。全局 Agenda 字号维持 16sp，字重增加到真实 SemiBold 600。说明创建先填标题再填正文，外部仅显示标题。

# Android 界面精简与枝叶重绘 0.12.2

依据用户补充的红圈截图，本次删除首页标题下的绿色短线和说明文字、四张分类卡片的左上角线性图标，以及尽快做标题前的闪电图标。卡片右侧箭头和卡片中的水彩插画保留；标题区相应收紧。

尽快做标题条改为淡蓝色 `#E5F0FB`。底部导航仅显示图标，保留无障碍名称、选中状态和原有点击区域。导航背景跟随当前页面底色，不再固定为白色；日历自定义背景颜色也同步应用到顶部栏、底部栏及系统栏背后的区域。三键系统导航关闭强制对比度蒙层。

日历「留些空白」上方的枝叶不再引用 PNG，改由 `CalendarBranch.kt` 使用原生 Compose Canvas 绘制贝塞尔路径。统一 156×122 坐标、等比例缩放、居中放置，不旋转；所有叶片的根部与主茎使用相同接点坐标，底线水平，圆形采用相同 X/Y 比例。已依据实际 Kotlin 路径数据放大渲染并检查，预览文件为 `artifacts/0.12.2-calendar-branch-review.png`（绘图检查图，不是手机截图）。

包名继续为 `com.agenda.local.preview`，版本 `0.12.2-blue` / 17。安装包为 `artifacts/Agenda-0.12.2-blue-preview.apk`，使用同一电脑签名，可覆盖更新现有预览版；原 Agenda 正式数据应用不改动。

验证结果：最终 APK 编译、Lint 检查均通过；用户连接手机后，adb install -r 返回 Success，已更新预览版。原生枝叶路径已生成放大绘图检查图。

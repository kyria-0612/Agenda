# 文档对照与发布检查 · 0.11.0

日期：2026-10-29。批次 E 首轮：按用户要求核对文档、修正偏差并验证兼容与页面恢复。下列实现检查不代替全部发行验收。

## 判定依据

用户本次明确选择优先于旧文档；已确认的《技术架构决策记录》D01–D22 覆盖相冲突的早期构想；已获认可的 0.5.0 视觉动效继续作为基线。浏览器历史试验和已被替代的方案不作为新增功能要求。版本报告记录当时事实，不将历史待办当作当前缺失。

本次确认两项产品边界：尽快做为今天至今天后第六天、排除逾期；任务内说明和关联材料纳入第一版，内部子清单延后。

## 数据兼容

Room 显式迁移 v5 → v6，任务增加可选说明列，新增任务与材料复合关联表；保留 v1 起的全部显式迁移。已有任务默认说明为空且没有关联。删除恢复集升级 v3，兼容读取旧 v1/v2；备份格式独立升级 v3，兼容读取旧 v1/v2。无破坏性重建。

真实手机只用于覆盖升级、数据一致性和首页显示核对。删除、恢复与测试数据操作限定在模拟器及隔离测试目录。

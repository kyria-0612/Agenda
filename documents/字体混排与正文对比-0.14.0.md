# Android 字体混排与正文对比 0.14.0

按照用户确认的分工实施：

| 内容 | 本地字体 |
| --- | --- |
| 顶部 Agenda 品牌 | Space Grotesk 真实 SemiBold 600，固定使用，不受正文选项影响 |
| 英文标题 | Space Grotesk，含本地 400 / 600 字重 |
| 英文正文 | Times New Roman / Lato，可即时切换，记住选择 |
| 数字与 ASCII 标点 | Manrope，启用 `tnum` |
| 中文标题、分组标题、阅读提示 | Agenda Serif → Noto Serif SC |
| 中文正文、任务、表单、按钮 | Agenda Sans → Noto Sans SC |

原生 Compose 没有 CSS `unicode-range`，这里用 `agendaAnnotated` 实现 Agenda Mixed 的等价字符路由：数字 U+0030–0039 与 ASCII 标点 U+0021–002F、U+003A–0040、U+005B–0060、U+007B–007E 使用 Manrope；英文字母按标题/正文/品牌角色选择字体；中文字符和中文标点使用对应 Noto 字体。连续同字体字符合并为一段，保留字距和连字，不拆分代理对和组合音标。

所有主视图、浮层、提示条以及输入字段统一使用这套规则。标题字体不会传播到普通按钮和任务正文；输入转换只改变字形样式，字符串、选择位置和业务数据不变。统一禁用模拟字重，Agenda 品牌使用单独的本地真实 600 字重资源；标题和数字所用 600 字重也由本地可变字体生成静态实例。

顶部品牌仍放在全宽 Box 的中点，不参与左右按钮 Row 排版，因此两侧按钮数量不同也不会推偏品牌。

切换入口：日历页顶部日期/标题区域 →「背景与文字」→「英文正文字体」→「Times New Roman / Lato」。下方有包含英文、数字和 ASCII 标点的即时预览，选择自动保存。主题、中英文开关继续可用。

字体全部本地加载：Space Grotesk、Manrope 沿用工程本地来源；Noto 使用本机完整字库，400/600 实例各覆盖约 3 万字符，减少依赖系统缺字回退。Times New Roman 与 Lato 采用本机同名字体文件，不使用相近字体代替。来源、字重、字形数、校验值与原文件嵌入标志记录于 `android/app/src/main/assets/font-licenses/typography-0.14.0-sources.json`，原字体元数据一并保留。

普通 Android 应用无法修改手机系统状态栏时钟、电量或系统弹窗的字体；应用内部的日期、时间、数量和状态文案均已纳入混排。

版本 `0.14.0-typography` / 20，包名 `com.agenda.local.preview`。安装包 `artifacts/Agenda-0.14.0-typography-preview.apk`。字体准备脚本为 `android/tools/prepare_typography_fonts.py`。

交付验证：最终编译、Lint 检查通过；6 项字体路由/内容保护测试和 5 项主题/翻译测试均通过；Manrope 400/600 的 tnum 替换后数字宽度均为 1240 字体单位，真实 600 字重已核对。手机覆盖安装返回 Success，更新预览版时保留现有数据。

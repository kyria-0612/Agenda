# Android 参考图页面改版 0.12.0

本次只修改 Android 原生 Compose 前端。参考用户提供的首页、日历两张图片，调整淡绿色背景、无衬线标题、四张分类卡片、波浪装饰、尽快做区域、日期卡片、日历插画和底部导航。

## 保留的行为

分类卡片继续原位展开；任务数量、日期、截止任务和休闲活动来自实际数据。日程仍支持完整视图与紧凑视图切换、日期展开、添加/编辑日程、周计划、自定义背景及文字。底部首页对应原行动页，事项仍保留原关系图/任务板入口，日历对应原日程页；没有将事项错误地标为专注。

## 插画与还原边界

六张透明 PNG 通过内置 image_gen 生成并保存到 android/app/src/main/res/drawable-nodpi/meadow_*.png。具体提示词与来源记录见 reference-art-prompts.json。插画与系统中文字体为依据截图重建，未经逐像素一致性验收。截图中的示例日期、任务数量和系统状态栏不硬编码。

## 手机安装

手机旧版为 com.agenda.local，0.11.0-local / 14。旧版证书和当前电脑证书不一致，当前项目没有原私钥，不能覆盖更新；不卸载旧版、不清除数据。

使用 -PagendaPreview=true 生成 com.agenda.local.preview，名称为「Agenda · 新版预览」，版本 0.12.0-meadow / 15。独立安装的数据从空白开始，不自动拷贝旧版数据。需要覆盖旧版时必须提供原签名文件；也可在用户明确选择后另外安排备份与迁移。

## 构建

本机官方 JDK、SDK、Gradle 缓存均位于 android/.build-tools 或 .gradle-user-home，并已忽略。临时盘符用于处理中文目录的 Java worker 兼容问题，构建结束释放。

在工作区根目录执行：

```powershell
python agenda-main/android/tools/build_reference.py :app:assembleDebug :app:lintDebug -PagendaPreview=true
```

现有 domain 14 项与 data 6 项单元测试已通过。用户选择自行在手机核对视觉和交互，本次不代替用户进行手机业务验收。

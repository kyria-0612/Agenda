# 日常功能补齐 · 0.10.0

日期：2026-10-29。正式版补全计划批次 D，沿用用户认可的视觉和动效。

## 实现范围

- 每日应用内提醒：按设备本地日期，每天首次进入检查明天至大后三天内到期的未完成任务，不包括今天、逾期或无截止日期的任务。空结果也记录检查；同一天重启或恢复同日备份不重复提示。编辑、撤销窗口及备份操作期间延后检查；无系统通知。
- 任务板位置：保存顶层对象和独立任务的双列空间格位，长按移动，目标被占用时交换位置，允许保留空位。位置独立于任务分类、截止时间和业务优先级；新增、归属改变、删除撤销时统一整理有效位置。
- 日程背景：支持四种浅色纯色、复制保存自选图片、最多两行且 200 字以内的文字。图片以浅色显示保持文字可读；保存前校验、限额及缩略解码，单张最多 50 MB。失败不发布新图片或文字，保留填写内容；切换纯色后清理不再引用的应用副本，不修改手机原图。
- 休闲活动：独立添加、编辑、删除与短暂撤销，不进入普通任务、周计划、尽快做或任务完成统计；保留「也可以什么都不做」。

## 数据与备份

Room 显式迁移 v4 → v5，增加空间位置、休闲活动、背景资源、背景文字配置和每日检查记录；旧迁移链继续保留。图片位于每个数据集自己的 assets 目录，与材料分开管理。

备份格式升级到 v2，包含上述全部记录及背景图片，继续支持读取 v1。旧备份恢复后初始化新增配置；v2 恢复保持位置、休闲活动、背景及每日检查记录。恢复仍先校验、自动保存恢复前快照，再发布完整新数据集；失败保留原数据。

23 项原生界面流程检查通过；最终交付 APK 另通过背景保留、悬挂日期展开及背景编辑入口 3 项复查，展开卡片保持在可视区域。截图见 android/review/daily-features-0.10.0，脚本为 android/tools/daily_features_review.py 和 daily_features_final_smoke.py；长按拖动测试仅允许明确选定的模拟器，不能在真实手机运行。系统图片选择器的缩略图布局通过无障碍描述识别；恢复切换后一次 UIAutomator 进程退出，恢复后的界面复查重试通过，数据库恢复正常。

手机已覆盖升级到 0.10.0，首页品牌与导航显示、进程存活及启动错误检查通过。升级前后的对象、任务、材料、说明、日程、周计划六类业务表计数及 SHA-256 摘要完全一致，schema 从 v4 显式迁移至 v5。记录另存 android/review/phone-upgrade-0.10.0，仅保留摘要，不保留个人记录正文；未在手机执行删除或整库恢复测试。

# Android 网络视图与统一背景 0.12.3

网络视图仅为对象延伸出的三个入口添加原生线性图标：任务为方框勾选，材料为叠层，说明为圆圈信息。独立任务及具体任务节点不添加火箭、数学或衣服等图标。

对象节点保持原有尺寸、圆角和点击展开方式，底色改为深灰绿色 `#456A5D`，文字纯白。其他节点框使用纯白 `#FFFFFF`，保留原有节点位置、边框与连接关系。不添加参考图黄圈的描边或额外外形。

首页、事项（关系图及任务板）、日历共用一层原生波浪背景，默认底色 `#F4F8F5`，上、下两处浅绿色渐变曲线参照用户提供的截图。背景从顶部系统栏到应用底部连续绘制，不再在正文区域单独重起一层背景，也不再把首页设为独立蓝色。日历已有的背景颜色设置同步作为三个主视图的底色；用户的自选背景图片与文字继续保留。

版本为 `0.12.3-mist` / 18，包名仍为 `com.agenda.local.preview`。安装包：`artifacts/Agenda-0.12.3-mist-preview.apk`。本轮不改变业务数据或数据库。

构建结果：APK 编译和 Lint 检查通过。手机更新安装返回 Success；本轮仅更新预览版，保留已有数据。

# 说明、玻璃首帧与悬挂收起优化 · 0.5.0

日期：2026-10-28。对应用户本轮四项反馈。

用户验收记录：体验后表示“基本上这一版没啥问题了”。0.5.0 据此作为本阶段通过的交互基线，后续转入真实数据开发。

## 实施

1. 说明保存独立 ID、标题、正文。创建先填写标题再填写正文；关系图、任务板、说明列表和搜索结果仅展示标题，点击以 ID 打开对应正文。搜索匹配标题和正文，同名说明也能分别打开。空标题或空正文提供提示，关闭草稿仍有放弃确认。
2. 玻璃背景采样和模糊移至面板挂载之前，准备完成后一次呈现最终材质。移除 `glass == null` 时 .98 不透明色面的首帧过渡；在同一浮层流程内切换内容复用背景，不重复出现准备前样式。背景捕获失败有日志并保持透光色面，不恢复旧不透明面板。
3. 悬挂日期用固定数量的轻量日期条替代在宽度动画中扩展 LazyRow。只为打开/正在收起的卡片保留详情，其他日期不构建隐藏的全天详情；自定义布局只放置视口附近的日期，避免每帧遍历绘制屏幕外卡片。聚焦滚动与宽高使用同款弹簧，取消 500ms 后的再次校正；今日底色在绘制阶段随进度变化，空白提示在收起结束附近淡入。保留横向浏览、展开聚焦、内部滚动及返回收起。
4. Agenda 保持 16sp 与视口居中；从现有本地 Space Grotesk 可变字体生成真实 600 字重并注册，字重由 Medium 增至 SemiBold。普通文字仍使用原有 400 字重。

## 已验证

- 15 项规则测试通过（domain 9 / data 6），包括说明标题/正文分别保存、对象归属、同名说明 ID 和正文互不混淆；构建与 Lint 通过，Lint 0 错误。
- `tools/notes_glass_smoothness_review.py` 原生回归 19 项通过：既有和新增说明标题展示/点击正文、正文搜索返回标题、空标题校验、玻璃首帧、连续三轮展开聚焦和收起，以及无应用异常/背景准备失败。
- 5 次独立玻璃挂载的首次绘制均带有已准备的模糊图像。软件模拟器准备耗时分别 470、198、199、301、225ms；这段时间用于准备最终材质，不能解释成旧面板仍展示半秒，也不作为手机延迟结论。
- 首轮三轮收起未新增详情内容树，记录到 13、18、17 个不同尺寸；最大相邻尺寸事件间隔为 63、48、40ms。展开中心为 542.5px，视口中心 540px。尺寸事件不是完整渲染帧统计，不据此宣称稳定 60fps 或真机卡顿完全消除。
- 中间版本的空闲模拟器对照：0.4 的 p90/p95 为 65/150ms，0.5 中间版本为 73/93ms，长停顿减少但整体帧率未全面改善。因此继续增加了视口外绘制裁剪，而未将这次中间测量写成“流畅度全部通过”。原始统计保留于 `idle-comparison-*.txt` 与 JSON。
- 最终视口裁剪版本追加 10 项日期专项检查全部通过，三次收起均无新详情树，连续尺寸分别 14、17、17 个；最大尺寸事件间隔 63、43、47ms。预热后进行三组展开/收起，应用帧统计 p90/p95 为 65/81ms，janky 15.87%；旧版同类空闲模拟器记录为 65/150ms、27.17%。最终版明显减少长尾停顿，但 p90 未改善，不将其宣传为稳定 60fps。最终原始记录见 `date-final-report.json` 和 `final-0.5-gfxinfo.txt`。
- 字体文件权重值为 600，品牌文本渲染高度仍为 53px，保持居中；已查看原生截图，确认标题正文顺序与仅标题展示。
- 证据：`android/review/notes-glass-smoothness-0.5.0/`，包含截图、UI 树、首帧日志、尺寸与内容树日志及应用帧统计。
- 最终调试包：`artifacts/Agenda-motion-0.5.0-debug.apk`，签名校验通过；SHA256 见同目录清单。
- 原生录屏 `date-expand-collapse.mp4` 与 `glass-first-open.mp4` 已保存。录屏不与上面的性能采样同时进行。
- 已覆盖安装到连接手机，系统报告 `versionCode=5`、`versionName=0.5.0-motion`；没有自动操作手机界面，由用户打开新版本体验。

# Android 双色主题与中英文 0.13.0

绿色版按用户确认的 0.12.3 保留，默认仍为绿色、中文。已保存原安装包 `artifacts/Agenda-0.12.3-mist-preview.apk` 和源码快照 `artifacts/Agenda-0.12.3-approved-source.zip`。

新增灰蓝主题：底色 `#E9EFF3`、亮青点缀 `#5BA9B1`、深灰蓝文字 `#43515F`。三个主视图、顶部和底部、分类卡片的淡色装饰、日期选中态与浮层控件跟随主题。绿色配色使用原来的值，布局、卡片插画和网络图功能不变。

入口仍在日历页顶部日期/标题区域，点击打开「背景与文字」。面板中的「界面色调」提供「绿色 / 灰蓝」，「语言 / Language」提供「中文 / English」，点选立即生效并自动保存，不需要保存背景文字才生效。「保存背景与文字」继续负责用户自选背景图片与自定义文字。

主题和语言写入应用私有 `interface-settings` 偏好，不修改任务数据库，也不把用户填写的对象名、任务名、材料标题、说明正文翻译或写回。恢复业务数据不重置界面语言。默认提示语在英文界面以英文显示，自定义文字保留原文。

英文文案包含主视图、创建和编辑、搜索、日历、休闲活动、材料和图片查看、周计划、备份恢复、删除撤销、错误与进度提示，共 326 条。语言切换只作用于明确的界面文案与模板，模板参数保留原始用户内容。英文网络分支增加必要宽度，避免 Materials 等名称被挤出框。

英文源目录为 `android/app/src/main/assets/i18n/en.json`；修改后运行 `python agenda-main/android/tools/generate_ui_catalog.py` 生成 Kotlin 目录并检查界面文案覆盖率、模板参数一致性。`localize_interface.py` 是本次一次性源码迁移工具，不要重复执行。

包名仍为 `com.agenda.local.preview`，版本 `0.13.0-themes` / 19。安装包为 `artifacts/Agenda-0.13.0-themes-preview.apk`。

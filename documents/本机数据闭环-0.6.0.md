# 本机数据闭环：0.6.0 交付记录

实施开始：2026-10-28。交付：2026-10-29。

## 已交付

保留用户认可的 0.5.0 视觉与交互基线，接入 Room、DataStore 和 ViewModel，完成第一条真实数据流程：创建对象与任务 → 安排引用日程 → 在日程完成任务 → 事项与行动同步 → 强制停止并重开后保留。

- 对象、任务（分类、归属、截止日期等）、说明标题与正文、材料元数据、日程均保存到本机数据库。
- 日程支持引用任务或独立临时安排，可选钟点和独立显示名称；引用共用任务完成状态，临时安排独立完成。重复引用按任务、日期、时段、钟点判重，失败保留表单。
- 材料复制到应用内部，使用 UUID 文件标识；复制成功后才发布条目，失败清理暂存，启动时清理受管的无引用文件。同名材料可分别保存。
- 保存当前页面、任务板模式和日程模式。首次启动为空白，不填充演示数据。
- 数据库 schema 版本为 1，已导出结构，不启用破坏性重建；真实升级迁移在后续结构变更时实现并测试。

## 安装与本轮体验

安装包：`artifacts/Agenda-local-0.6.0-debug.apk`。应用显示名「Agenda」，包名 `com.agenda.local`，与「Agenda · 动效样机」分开，旧样机保留。

用户本轮主要体验：创建一个对象和带截止日期的任务，添加说明与材料，把任务安排到日程，勾选完成后核对其他页面，再关闭并重开核对保存结果。
